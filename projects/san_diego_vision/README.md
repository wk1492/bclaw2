# San Diego Sports Science Vision — Knowledge Base

## What this folder is

A structured knowledge base for a youth STEM + sports performance initiative
seeded from operator conversations. Files capture verified facts, unverified
leads, open questions, and exploratory ideas — clearly labeled.

## How future agents should use it

- Read all files before acting on any single file.
- Treat `VERIFIED_FROM_OPERATOR` items as facts. Treat `UNVERIFIED` items as
  leads to validate before acting on them.
- Never merge UNVERIFIED into VERIFIED without explicit operator confirmation.
- Use OPEN_QUESTIONS.md as the primary action queue.
- BCLAW/BCLAW4 is the deterministic project memory substrate; these files are
  human-readable overlays, not the ledger.

## Labeling convention

| Label | Meaning |
|---|---|
| `VERIFIED_FROM_OPERATOR` | Operator stated this directly |
| `UNVERIFIED` | Plausible but not confirmed by operator |
| `EXPLORATORY` | Speculative idea; needs scoping before action |
